## 功能特性

### 文件管理
- 文件列表浏览，单击文件夹进入，长按弹出操作菜单
- 文件夹操作：打开、下载、分享、详细信息、移动、复制、重命名、删除、去重此目录
- 文件操作：播放/预览、下载、分享、详细信息、移动、复制、重命名、删除
- 多选批量操作（整理模式）：批量移动、批量复制、批量删除
- 文件类型图标按类型着色
- 排序（按文件名/大小/创建时间/修改时间），默认按修改时间降序
- 文件列表显示时间和文件大小

### 上传下载
- 上传文件/文件夹（保留目录结构）
- 单文件下载、文件夹批量打包下载（自动加.zip后缀）
- 下载管理：自动扫描下载目录，支持打开/安装APK/删除
- 上传/下载时自动保持屏幕常亮
- 自定义下载缓存目录

### 预览
- 图片/视频/音频在线播放
- 文本文件查看、PDF/Word/Excel预览
- HTML文件网页预览

### 分享与直链
- 创建分享（随机提取码/自定义提取码/无提取码）
- 我的分享管理、接收分享
- 直链解析：粘贴分享链接→解析文件→获取直链→生成二维码

### 回收站
- 恢复到原位置/指定目录
- 彻底删除单个/批量文件、清空回收站

### 其他
- 日间/夜间/跟随系统主题，所有弹窗按钮跟随主题
- 网页端管理（App内打开桌面版网页）
- 离线下载（磁力/HTTP链接）
- 多账号管理（手机号/邮箱脱敏显示）
